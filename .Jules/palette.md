## 2025-06-11 - Accessibility for Custom Animated Dropdowns
**Learning:** Custom animated dropdowns built with generic components (like Framer Motion `motion.div`) require explicit ARIA roles (`menu`, `menuitem`, `presentation`) for screen readers to correctly interpret them as menus. Furthermore, non-native dropdowns must manually implement expected mouse and keyboard interaction patterns, specifically closing on "Escape" key press and when a user clicks outside the component boundary, to be considered accessible and usable.
**Action:** When building or enhancing custom select/dropdown menus in React, ensure the trigger has `aria-haspopup` and `aria-expanded`, the container has `role="menu"`, items have `role="menuitem"`, and a `useEffect` handles global `mousedown` and `keydown` events for "click outside" and "Escape" key close behaviors.
