## 2024-06-02 - Accessible Custom Animated Dropdowns
**Learning:** Custom animated dropdowns (like the ThemeSwitcher built with Framer Motion) inherently lack the semantic structure and keyboard navigation of native `<select>` or `<details>` elements. When a screen reader encounters a basic `<button>` that toggles a generic `<motion.div>`, it cannot announce the menu state or relationship to the toggle button. Furthermore, without explicit keyboard listeners, keyboard-only users cannot dismiss the menu intuitively (e.g., via the Escape key) or lose focus when clicking outside.
**Action:** When building custom dropdowns, always implement the `menu` pattern. Ensure the toggle button has `aria-haspopup="menu"` and `aria-expanded`. The dropdown container should have `role="menu"`, interactive children should have `role="menuitem"`, and non-interactive structural elements should have `role="presentation"`. Additionally, attach listeners for Escape keydowns and outside clicks to handle dismissal robustly.
