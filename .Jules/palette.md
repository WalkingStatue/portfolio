## 2024-06-04 - Accessible Custom Framer Motion Dropdowns
**Learning:** When building custom animated dropdowns with Framer Motion, standard HTML select/option accessibility is lost. We must explicitly construct the accessible tree using `role="menu"`, `role="menuitem"`, `aria-haspopup`, and `aria-expanded`. Additionally, to ensure a complete interaction loop that mirrors native behavior, we must manually wire up Escape key and click-outside event listeners to close the menu, otherwise it remains trapped open for keyboard users or those clicking away.
**Action:** Always add ARIA roles (`menu`, `menuitem`, `presentation` for non-interactive elements) and bind `mousedown` (for click-outside) and `keydown` (for Escape) event listeners when creating custom toggleable dropdown menus.
