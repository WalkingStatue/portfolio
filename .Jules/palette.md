## 2024-05-18 - Missing Focus Styles in Animated Interaction Wrappers
**Learning:** When using components like `MagneticButton` that wrap internal interactive elements (like `<a>` or `<button>`) with framer-motion `motion.div` tags, the native focus outlines get obscured, hidden, or visually mismatched with the animated bounds, creating a critical accessibility failure for keyboard users. Furthermore, nesting `<a>` inside `<button>` or custom components that render interactive tags violates HTML semantics.
**Action:** Always ensure that structural wrapper components (`MagneticButton`) explicitly render as the root interactive tag (`<a>` or `<button>`) by accepting `href` or `onClick` props directly, and explicitly add `focus-visible` utility classes to these root elements rather than relying on browser defaults which may conflict with nested animation structures.
