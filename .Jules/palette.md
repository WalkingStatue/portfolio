## 2025-09-05 - Avoid Nested Interactive Elements in Framer Motion Wrappers
**Learning:** When building custom interactive components (like a MagneticButton built with Framer Motion), wrapping nested interactive elements (like `<a>` tags inside `<button>` or custom handlers) creates invalid HTML nesting and severe accessibility issues for screen readers. Furthermore, applying motion wrappers can sometimes obscure or clip native browser focus outlines during keyboard navigation.
**Action:** When a wrapper component needs to act as a link, dynamically render it as the root `<a>` tag by passing down routing props (like `href`), and use `<span>` for styling its children. Additionally, explicitly apply utility classes for focus states (e.g., `focus-visible:outline-none focus-visible:ring-2`) to the root element to ensure keyboard accessibility is not lost.
